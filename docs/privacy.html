🛡️ Quick Privacy Summary

Social Autopilot is a 100% self-hosted, local-first automation application. We do not operate central user tracking databases, telemetry servers, or data brokerage systems. All configuration keys, OAuth tokens, content queues, and generated media assets reside exclusively on the user's own local filesystem and communicate directly with user-authorized third-party APIs (such as LinkedIn and Meta).

01 What Social Autopilot Is

Social Autopilot is an open-source, automated multi-format social media scheduling and publishing system. It allows developers, creators, and engineering leaders to generate and schedule technical posts, infographics, and short vertical videos for publishing to social platforms like LinkedIn and Meta (Facebook Page / Instagram).

02 Self-Hosted & Local-First Architecture

Unlike Software-as-a-Service (SaaS) platforms, Social Autopilot runs directly on your local machine, server, or private cloud instance.

  • No Remote Server Database: Social Autopilot has no central cloud server that collects or stores your login credentials or personal profile data.
  • Local Configuration Storage: All environment variables and access tokens are loaded from local environment files (.env) on the host machine.
  • Local Queue: All scheduled tasks and publication statuses are stored locally in a CSV file (schedule.csv).
  • Local Media Rendering: Media assets (cards, voiceovers, MP4 videos) are generated and stored locally in the output/ directory.

03 Information Processed by Social Autopilot

Depending on how you configure and run Social Autopilot, the following categories of data are processed locally on your system:

Data Category Storage Location Purpose & Handling
API Credentials & Tokens Local .env file Stores user-provided LinkedIn Access Tokens, Meta Page Tokens, and Google Gemini API keys. Strictly excluded from version control via .gitignore.
Scheduled Content & Captions Local schedule.csv Stores topic titles, hashtags, custom captions, execution timestamps, and per-platform publication status logs.
Generated Media Assets Local output/ directory Stores generated PNG graphic cards, MP3 voiceover files, and MP4 vertical video files.
Execution Logs Local autopilot.log Stores timestamped task status logs, error messages, and external publication URLs for debugging.

04 Third-Party Services & API Interactions

Social Autopilot connects directly to the following external APIs using the credentials you configure:

1. LinkedIn API (LinkedIn REST / UGC Posts API)

When LinkedIn publishing is enabled, Social Autopilot communicates directly with LinkedIn's official REST API endpoints (https://api.linkedin.com/v2/):

  • Permissions Used: w_member_social (for personal profile posts) or w_organization_social / Community Management API (for company page posts).
  • Data Transmitted: Post caption text, uploaded media binaries (PNG/MP4), and the author Uniform Resource Name (URN: urn:li:person:... or urn:li:organization:...).
  • Data Received: LinkedIn post identifiers (e.g. urn:li:share:...) and status codes to record publication success in your local schedule log.
  • No Scraping: Social Autopilot does not scrape, harvest, or store LinkedIn user feeds, connections, or contact lists.

2. Meta Graph API (Facebook Page & Instagram Business)

  • Permissions Used: pages_manage_posts, pages_read_engagement, and Instagram Content Publishing.
  • Data Transmitted: Page captions, images, and videos published directly to the user's authorized Facebook Page or Instagram Business container.
  • Data Received: Post IDs and publication status confirmations.

3. Google Gemini API (Optional AI Content Engine)

  • Usage: Used to generate technical post drafts, takeaway points, and video scripts based on user-provided keywords or topics.
  • Data Transmitted: Only the topic title, hashtags, target persona, and content type parameters. User personal account data is not sent to Gemini.
  • Bypass: When you supply an exact custom caption (--caption), Gemini API generation is completely bypassed.

4. Microsoft Edge TTS (Local Voiceover Synthesis)

  • Usage: Synthesizes neural voiceover audio for vertical videos without requiring paid cloud API keys.
  • Data Transmitted: Text string of the voiceover narration script.

05 Cookies, Analytics, and Tracking

Zero Web Tracking: Social Autopilot contains no web cookies, tracking pixels, telemetric beacons, or third-party analytics SDKs (such as Google Analytics or Mixpanel). We do not track your IP address, device fingerprints, or runtime activity.

06 Data Retention and User Deletion Rights

Because all data is stored locally on your machine:

  • Immediate Deletion: You can delete all local data at any time by clearing the schedule.csv file, deleting the output/ directory, or removing your .env files.
  • Revoking Access: You can revoke Social Autopilot's access to your LinkedIn or Facebook accounts at any time through your LinkedIn Developer App settings or Meta App Permissions. Once revoked, Social Autopilot cannot publish on your behalf.

07 Security Measures

Social Autopilot enforces strict local security best practices:

  • Git Protection: The repository's .gitignore strictly excludes all .env* credential files, virtual environments, runtime logs, and media artifacts from being committed to source control.
  • Credential Isolation: No OAuth tokens or API secrets are hardcoded in application scripts or public documentation.
  • Atomic File Operations: Task queue updates use atomic temporary file replacement to prevent data corruption during power interruptions.

08 Children's Privacy

Social Autopilot is designed for developers, engineering professionals, and organizations. It is not intended for use by individuals under the age of 13.
